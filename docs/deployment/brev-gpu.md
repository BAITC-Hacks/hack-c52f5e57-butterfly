# GPU для Butterfly в NVIDIA Brev

Проверено по официальным источникам 2026-09-23. Это рекомендация конфигурации,
не подтверждение аренды, текущего тарифа или измеренной производительности.

## Что выбрать

Начать с **одной NVIDIA L4 в VM Mode**. В Brev открыть **GPUs → Create Instance**
и выбрать доступную конфигурацию с этой GPU.

| Параметр | Рекомендуемая стартовая конфигурация |
|---|---|
| GPU | 1 × NVIDIA L4 |
| VRAM | 24 GB по спецификации NVIDIA; в каталоге Brev указано 22 GB |
| CPU | Желательно 8 vCPU |
| Оперативная память | Желательно от 32 GB |
| Диск | Начать со 100 GB, если провайдер допускает такой размер |
| Среда | VM Mode, Linux x86_64 с CUDA и Docker |
| Управление | Stoppable/rebootable; возможность настроить сетевые порты |
| Имя | `butterfly-meeting-minutes` |

CPU, RAM и диск — проектные ориентиры, не требования поставщика моделей.
Точная комплектация и доступность зависят от карточки провайдера.

[NVIDIA указывает 24 GB памяти L4](https://www.nvidia.com/en-us/data-center/l4/).
[Каталог Brev указывает 22 GB](https://docs.nvidia.com/brev/reference/gpu-types).
Причина расхождения здесь не установлена: ориентироваться на память конкретного
instance и проверить её через `nvidia-smi` после запуска.

Если L4 недоступна, сравнить **1 × A10/A10G** с сопоставимой доступной памятью.
Если **L40S** предлагается по такой же или меньшей полной цене, её можно выбрать
ради большего запаса VRAM. Это условие выбора, не утверждение о текущих ценах.

## Какие модели запустим

- **faster-whisper large-v3** — RU/KK/mixed транскрипция.
- **pyannote speaker-diarization-community-1** — интервалы говорящих; имена
  подтверждаются отдельно по списку участников.
- **Qwen3-4B** — извлечение поручений и summary; предпочтительно квантованный
  вариант с ограниченным контекстом и проверкой результата по цитатам.

Начальный режим — одна встреча в очереди, последовательные стадии обработки.
Не планируем обучение весов или загрузку нескольких больших моделей одновременно.
Приёмочный тест должен измерить память, время и качество на постановочной встрече
RU/KK/mixed. Достаточность конфигурации для выбранной нагрузки пока не измерена.

Для faster-whisper текущая документация требует CUDA 12 и cuDNN 9.
Community-1 требует принятия условий Hugging Face для первоначального получения
весов; затем поддерживает offline-загрузку. Ключи не входят в git или frontend.

Источники: [faster-whisper](https://github.com/SYSTRAN/faster-whisper),
[Community-1](https://huggingface.co/pyannote/speaker-diarization-community-1),
[Qwen3-4B](https://huggingface.co/Qwen/Qwen3-4B). Получены 2026-09-23.

## Бюджет $50

Предлагается планировать **$40 на compute и $10 резерва на диск и непредвиденные
расходы**. Это распределение бюджета, не актуальный прайс Brev и не разрешение
на автоматическую покупку.

| Условная цена compute | Часы работы на $40 |
|---|---:|
| $0.50/час | 80 |
| $1.00/час | 40 |
| $1.50/час | 26.7 |
| $2.00/час | 20 |

Формула: `часы = 40 / цена_compute_в_час`. Диск и прочие сборы проверяются отдельно;
резерв не гарантирует их покрытия. Рабочий ориентир для выбора — около $1/час
или ниже, если такая подходящая карточка доступна. Точный текущий тариф и срок
сдачи пока неизвестны.

Запускать GPU, когда код готов к проверке моделей. На длительных паузах останавливать
stoppable instance; storage продолжает тарифицироваться. Сайт Vercel может оставаться
доступным, но новая обработка требует работающего Brev backend. Для репетиции и
показа оставить VM включённой: после остановки повторный запуск зависит от наличия
GPU у провайдера.

Источник: [Brev: lifecycle и billing](https://docs.nvidia.com/brev/concepts/gpu-instances),
получен 2026-09-23. Аренда в рамках подготовки этих документов не выполнялась.

## Сеть и выбор в консоли

1. Открыть [Brev Console](https://brev.nvidia.com/) → GPUs → Create Instance.
2. Выбрать 1 × L4, сравнить цену всей VM, RAM, диск и доступность остановки.
3. Выбрать VM Mode с CUDA/Docker. Назначение этой VM — backend нашего проекта;
   готовые agent/robotics Launchables для запуска этого стека не требуются.
4. Проверить итоговую цену и storage перед активацией. До этого код можно готовить
   без работающей GPU.
5. После старта получить SSH-доступ; сохранить приложение и модели на постоянном
   диске. Настроить HTTPS endpoint backend с авторизацией, ограничениями загрузки
   и CORS для frontend Vercel.

Встроенные Brev Tunnels требуют browser authentication. Поэтому нельзя считать
выданную tunnel-ссылку уже проверенным endpoint для загрузок с сайта Vercel;
нужно проверить реальный cross-origin запрос из чистого браузера. SSH port-forward
подходит для разработки, но публичное демо не должно зависеть от личного компьютера.

Источник: [Brev Console Reference](https://docs.nvidia.com/brev/guides/console-reference),
получен 2026-09-23.

При установленном и авторизованном Brev CLI список можно проверить без аренды:

```sh
brev search --gpu-name L4 --min-vram 20 --stoppable --flex-ports --sort price --wide
```

Это только поиск. Он не создаёт VM. Порог 20 GB позволяет увидеть L4 из каталога,
где модель обозначена как 22 GB; количество GPU, RAM и диск проверяются в результате.
Синтаксис: [Brev Search & Discovery](https://docs.nvidia.com/brev/cli/search-discovery),
получен 2026-09-23.
