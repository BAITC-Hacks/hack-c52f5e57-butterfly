Вход: ТЗ прочитано.

Выход/gate: Проверяемый контракт сценария и явные неизвестные.

Предварительный timebox: 20 минут. Rollback: Возврат к ТЗ и требованиям владельца.

Статус на момент планирования: done — документальные доказательства сохранены; runtime не заявлен.

## S1

Цель: Сопоставить self-hosted ASR/diarization/LLM, Fly и Telegram с первичными источниками.

Вход: Доступно ТЗ.

Выход/gate: Research artifact с источниками, confidence, gaps и falsifiers.

Предварительный timebox: 30 минут. Rollback: Пересмотреть выбор по новым источникам.

Статус на момент планирования: done — документальные доказательства сохранены; runtime не заявлен.

## S2

Цель: Подготовить переносимый frontend/API/worker и manifest моделей с тестовыми контрактами.

Вход: Research brief сохранён.

Выход/gate: Приложение стартует без GPU; API-ошибки и состояния честные; схема и fixtures валидны.

Предварительный timebox: 45 минут. Rollback: Отключить новые интеграции, вернуть рабочий каркас.

Статус на момент планирования: todo.

## S3

Цель: Получить вертикальный сценарий на GPU Brev: upload → ASR → speakers → actions → PDF/DOCX.

Вход: Код готов, выбран и согласован тариф, доступ к VM и весам.

Выход/gate: Запись RU/KK/mixed проходит реальный inference; результат с цитатами; файлы открываются.

Предварительный timebox: 120 минут. Rollback: Сохранить upload/review UI; GPU failures явные, без незаметной подмены fixtures.

Статус на момент планирования: todo.

## S4

Цель: Подключить Fly к событиям проверки и Telegram к разрешённым уведомлениям.

Вход: Core проходит, assets/licensing зафиксированы, Telegram настроен.

Выход/gate: Event IDs и exactly-once feedback; allowlist, дедупликация, негативные проверки; core работает при отключённых интеграциях.

Предварительный timebox: 60 минут. Rollback: Отключить optional-компонент с ошибкой.

Статус на момент планирования: todo.

## S5

Цель: Проверить качество, границы доступа, экспорт и переносимость offline.

Вход: Стабильный вертикальный сценарий.

Выход/gate: RU/KK/mixed eval с эталоном; cold start без сети; README воспроизводится; несделанное явно перечислено.

Предварительный timebox: 60 минут. Rollback: Вернуться к не прошедшему gate; не публиковать неподтверждённые метрики.

Статус на момент планирования: todo.

## S6

Цель: В финале опубликовать frontend на Vercel и проверить полный сценарий по внешней ссылке.

Вход: Backend доступен по HTTPS, проверки пройдены, доступ к Vercel.

Выход/gate: Публичная demo URL открывается в чистом браузере; файлы идут в Brev; основные результаты и экспорты проверены; commit/artifact зафиксирован.

Предварительный timebox: 45 минут. Rollback: Откат Vercel к последнему проверенному deployment.

Статус на момент планирования: todo.

## Open dependencies

Можно начинать каркас и контракты API без дополнительных доступов. Для реального GPU-run нужны доступ к Brev, конкретный тариф и weights Community-1; для Telegram — bot/chat и серверный secret; для финальной публикации — Vercel. До полноценного соответствия остаются runtime-тесты и трактовка meeting-bot/on-premise у организаторов.
